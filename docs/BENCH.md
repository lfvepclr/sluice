## 结论

- T1 相对 B1 的 p50 增量：+0.16 ms（隧道开销）
- T2（server 出口）p50 262.459µs vs T3（local 出口）p50 217.542µs：多一跳的代价
- B2（ingress health）p50 87.25µs，作为服务器基线

## 方法

- 每请求新建 TCP 连接，测量响应头到达（TTFB）与响应体收完（总耗时）。
- RSS / CPU 在场景首尾用 `ps` 采样取峰值；串行执行避免相互干扰。
- 复现：`cargo run --release -- bench --out docs/BENCH.md`。
